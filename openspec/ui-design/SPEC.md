# MarkFlow 界面原型与视觉规范

> 本文与 `index.html` 描述当前实现的主要界面结构，作为视觉和交互参考。原型是静态 HTML 展示，不承担真实文件操作、编辑器渲染和设置持久化。产品行为以应用代码和 `openspec/specs/` 对应模块规范为准。

## 页面骨架

应用窗口顶部由 macOS 原生标题栏显示窗口控制按钮与当前文件名；Webview 内部使用三行、两列 CSS Grid：工具栏 44px、主体自适应、状态栏 28px；主体由侧栏和编辑区组成。侧栏默认 250px，可拖动调整宽度并折叠；编辑区填满余下空间。焦点模式会降低工具栏、侧栏和状态栏的透明度，悬停时恢复。原型以 HTML 模拟原生标题栏，默认示例使用 MarkFlow 中文 README，并可在文件树切换到英文 README 和 `docs/设计规范.md`。

```text
┌──────────────────────────────────────────────────────────┐
│ 原生窗口标题栏（macOS 控制按钮 / 当前文件名）           │
├──────────────────────────────────────────────────────────┤
│ 顶部工具栏（品牌 / 文件操作 / 编辑命令 / 视图）          │
├──────────────────┬───────────────────────────────────────┤
│ 文件 / 大纲侧栏  │ 编辑区（居中内容容器，最大宽 1080px） │
│ 可调宽、可折叠   │                                       │
├──────────────────┴───────────────────────────────────────┤
│ 状态栏：自动保存错误提示（需要时）、文档统计、模式操作   │
└──────────────────────────────────────────────────────────┘
```

页面外观由 `src/styles/variables.css` 的 CSS 变量驱动。浅色主题使用暖白背景、白色表面和陶土强调色；深色主题使用深灰表面和明亮陶土色；护眼主题使用暖米色系。UI 使用系统无衬线字体，正文使用 Source Serif 4 与中文衬线回退，代码使用系统等宽字体。

## 顶部工具栏

顶栏横向排列并跨越整个窗口。按钮为 34px 方形热区，圆角 6px；悬停使用代码背景色，选中状态使用强调色及淡色强调背景。分隔线按功能划分按钮组，右侧弹性空白使工具栏按钮保持左侧排列。

从左到右包含：侧栏折叠、MarkFlow 品牌/最近文件菜单、打开文件夹、打开 Markdown 文件、新建、保存、导出、设置；文本格式命令；标题/引用/链接/列表/分隔线/代码块/图片/Frontmatter 插入命令；所见即所得与源码模式切换、专注模式。主题切换入口位于底部状态栏。窗口较窄时工具栏允许横向滚动。

工具按钮以 SVG 图标和悬停提示为主。品牌菜单展示最近文件与最近文件夹，并提供清除历史入口。导出按钮打开菜单，包含 PDF、Word、HTML 和打印操作。模式按钮用激活样式显示当前编辑模式。

## 侧栏

侧栏默认宽 250px，最小宽度 200px，右侧有拖动调整手柄。顶部是等宽的“文件”和“大纲”标签，选中项以强调色文字和底部边线标记。

文件视图显示工作区文件树：文件夹可展开，文件可选中；支持文件操作菜单、重命名/拖放等交互。文件树底部固定“打开文件夹”和“新建文件夹”操作。大纲视图按标题层级缩进，点击标题跳转到编辑区；切换到大纲时隐藏文件树底部操作栏。

侧栏可从顶栏按钮折叠至零宽。初始标签和树状态可由应用状态及设置恢复，具体行为以 sidebar 和 file-tree 实现为准。

## 编辑区

编辑区背景使用表面色，内容水平居中，内容容器最大宽度 1080px，内边距为 `56px 48px 120px`。所见即所得编辑器正文字号默认 18px、行高 1.7，使用 Source Serif 字体栈。标题、引用、行内代码、代码块、图片、表格、任务列表及图表等样式以 `src/styles/editor.css` 为准。

应用提供两种编辑模式：

- **所见即所得**：Tiptap/ProseMirror 编辑面，直接呈现格式化内容。
- **源码模式**：CodeMirror 6 编辑面，显示 Markdown 原文、等宽字体和语法高亮。

两种模式围绕同一文档状态切换。部分无法安全表示为富文本的内容可能要求保留在源码模式；相关准入与保真规则见编辑器规范。原型允许编辑示例内容，并提供简化的源码视图切换用于演示；它不运行 Tiptap/CodeMirror，也不保证完整 Markdown 往返保真。

## 状态栏

状态栏高 28px，使用页面背景色、顶部边线、12px 次要文字。左侧在自动保存连续失败时显示错误提示，并显示字数、行数和光标行列；右侧显示当前编辑模式，并提供设置、专注模式和主题入口。应用不常驻显示文档路径或“已保存”状态。左右信息由弹性空白隔开。

## 设置面板

设置通过模态遮罩居中显示，内容区使用双栏布局：左侧竖向分类标签，右侧滚动设置内容。分类为通用、外观、编辑器、图片和快捷键。模态使用表面色、细边线、圆角和柔和阴影，关闭按钮位于标题栏右侧。

当前面板覆盖自动保存与间隔、文件树性能配置、浅色/深色/护眼主题、正文排版、编辑行为、代码块、图片处理和快捷键等选项。具体字段、默认值和保存行为以 `src/components/settings.ts` 与设置类型定义为准。原型可切换分类、主题并编辑示意控件，但不会写入应用设置。

## 原型维护约定

- 修改真实应用的布局、组件、间距、颜色或交互后，同步更新本目录原型与规范。
- 先核对 `index.html`、`src/styles/` 和对应组件实现；不要从旧原型反推当前产品行为。
- 规范记录稳定的结构与样式要点，精确行为仍引用实现及功能规范，避免复制出第二份过期 API 说明。
- 原型以 MarkFlow 工作区和仓库 README（中英文）及 `docs/设计规范.md` 示例展示主界面；点击这些文件可切换文档。侧栏、最近记录、导出菜单、设置分类、主题、专注模式和模式切换可交互。打开文件使用浏览器文件选择器读取 Markdown；保存与 HTML 导出会下载示例副本，打印使用浏览器打印面板。PDF/Word 导出和文件夹操作只展示原型反馈，不调用 Tauri；设置值不会持久化。
