对现有 `commandRouter.ts` / `toolbar.ts` / `keyboard.ts` / `editorSurfaceBinding.ts` /

**已有（可在其上继续沉淀，不盲目重写）：**

- 统一 command router 雏形（`commandRouter.ts`）：`toggleInlineWrap`（bold/italic/strike/code）、
  `toggleHeading`（仅 level 1/2）、`toggleQuote`、`toggleList`（ul/ol）、`toggleCodeBlock`、
  `insertHorizontalRule`、`insertLinkMarkdown`、`insertImageMarkdown`，均为局部 CM transaction。
- toolbar/menu/keyboard/linkDialog 已路由到 active lossless view。
- paste 原始 EOL provenance 捕获（`onRawPasteText` → `pendingRawPasteProvenance`）。
- 图片保存前迁移为显式局部 patch（`preparePendingImagesForSave` → `applyImagePatches`）。
- 保存/autosave 走 lossless confirmed snapshot（`binding.save`），export 走 `buildLosslessExportRoot`。
- Lifecycle 自动化已在 `lifecycle.test.ts` 中覆盖零编辑、autosave tick、干净 Ctrl+S。

**缺口（本 Slice 必须补齐）：**

1. **Enter/Backspace/Delete command matrix 完全缺失**（任务 5.4）——lossless 下只用 CM
   `basicSetup` 的普通文本语义，无 markdown block-continuation / 空 list item 退出 /
   heading marker 退级等。这是默认编辑路径的最大 gap。
2. **命令测试覆盖面不足**（任务 5.2/5.4）：当前 `commandRouter.test.ts` 只有 collapsed
   selection 为主的 10 项；缺少 range/reversed selection、行首尾、嵌套、CJK/emoji、
   malformed fallback、Undo/Redo 的 table-driven 全覆盖。
3. **toolbar 命令在 Live Preview mode 下的 active binding 检查存在 P1 遗留**（P2 Reviewer
   已归口 P3 tasks 5.1-5.3）——需要确认预览 mode 下所有命令仍路由到同一 EditorView。
4. **Heading 命令只有 level 1/2**（P2 观察项 P2-A），与 toolbar `btn-h1/btn-h2` 一致；
   任务 5.2 要求 heading 命令迁移完整。
5. **Image 替换/删除入口缺失**：只有 toolbar `btn-image` 的插入；`onReplace` 钩子存在但
   当前没有被 WYSIWYG 或 lossless 的 context menu 调用（imageContextMenu 只有复制/另存为/
   复制路径/打开所在位置）。任务 5.3 要求图片插入/替换/删除 + 资源事务。
6. **History 显式 grouping 未实现**（任务 5.6）：未为 paste/Enter/结构命令/widget commit/
   bulk replace 显式加 History boundary；跨模式 Undo/Redo 只有零散依赖 basicSetup。
7. **P4 边界**：marker 隐藏（P4A/B）、task checkbox、image/GFM table widget、FrontMatter/
   Mermaid/PlantUML widget、Core Render IR 均不实现；table/task/frontmatter/reference/
   footnote/diagram/raw HTML 在本段为 exact source fallback（必须可读、可选、可编辑、
   可复制、可保存）。
