# document-size-tier Specification

## Purpose
定义文档打开时的默认编辑模式、源码大小确认及对应提示。

## Agent Context
- **源码入口：** `src/utils/file-size-tier.ts`、`src/ui/sidebar/fileops.ts`、`src/ui/degradation-bar.ts`。
- **关联规范：** `document-limits-settings`、`wysiwyg-markdown-reconciliation`、`codemirror-source-editor`。
- **不变量：** 大小和行数阈值只决定自动模式；源码大小阈值只触发打开确认；用户确认后继续打开。
- **验证：** `npm test -- src/utils/__tests__/file-size-tier.test.ts`；`npx openspec validate document-size-tier --strict`。

## Requirements

### Requirement: 文档尺寸等级分类

系统 MUST 在打开前读取文件大小和行数，并使用两项用户设置（WYSIWYG 文档大小、最大行数）决定默认编辑模式：只有大小和行数均未超过对应阈值时默认打开 WYSIWYG；任一超限即默认打开源码模式。源码文档大小阈值只决定打开前是否显示确认弹窗，不得禁止打开。用户确认后系统 MUST 继续打开文档。上述大小和行数阈值 MUST NOT 阻止用户手动切换到 WYSIWYG；手动切换使用正常 WYSIWYG 加载流程及 Markdown 安全往返检查，不得再以节点数、块级结构数或其他复杂度预算拒绝。

#### Scenario: 文档正常打开，无降级
- **WHEN** 用户打开一个 500KB、2000 行的文档，且使用默认阈值
- **THEN** 文档以所见即所得模式打开且不显示源码模式提示

#### Scenario: 大文档显示建议
- **WHEN** 用户打开一个 5MB、10000 行的文档，且使用默认阈值
- **THEN** 文档默认以源码模式打开
- **THEN** 文档标签栏下方显示可关闭的提示，说明文档因超过大小或行数阈值而默认以源码模式打开
- **THEN** 提示提供切换到所见即所得的操作，提示不阻止该操作

#### Scenario: 行数超限时默认源码模式
- **WHEN** 用户打开一个文件大小小于 WYSIWYG 阈值、但行数超过最大行数的文档
- **THEN** 文档默认以源码模式打开并显示可关闭提示
- **THEN** 系统不因行数超限显示源码最大大小确认弹窗

#### Scenario: 手动超驰降级
- **WHEN** 超过自动模式阈值的文档内容通过正常 Markdown 安全往返检查，且用户主动切换模式
- **THEN** 系统 MUST 渲染并显示所见即所得模式
- **THEN** 已关闭的源码模式提示不得再次阻止切换

#### Scenario: 巨量文件需要确认
- **WHEN** 用户打开一个文件大小超过源码文档大小阈值的文档
- **THEN** 系统显示确认弹窗询问是否继续打开
- **WHEN** 用户确认继续
- **THEN** 系统仍打开该文档并默认进入源码模式，不将大小阈值作为拒绝打开或只读的理由
- **WHEN** 用户取消
- **THEN** 系统不打开该文档

#### Scenario: 手动超驰降级的安全渲染
- **WHEN** 文档因大小或行数超过自动模式阈值而以源码模式打开，且 Markdown 可安全往返
- **THEN** 用户手动切换后系统按正常 WYSIWYG 流程加载并渲染文档
- **THEN** 系统不得因节点数、块级结构数量或阈值超限拒绝切换

#### Scenario: 手动模式切换不改变内容
- **WHEN** 用户对已打开文档手动切换编辑模式
- **THEN** 文档内容、保存状态和撤销历史保持一致，除非资格检查因独立的安全原因拒绝切换

### Requirement: 文件打开前预读取元数据
系统 MUST 在将完整文件内容加载到编辑器之前读取文件元数据（大小、行数）。

#### Scenario: 元数据读取成功
- **WHEN** 用户触发文件打开
- **THEN** 系统调用文件元数据能力获取文件大小和行数
- **THEN** 系统根据元数据确定默认编辑模式，以及是否需要源码大小确认

#### Scenario: 元数据读取失败
- **WHEN** 文件元数据读取失败
- **THEN** 系统记录错误并继续使用安全的默认打开策略
- **THEN** 系统显示非阻塞元数据提示

### Requirement: 可配置阈值
打开策略阈值 MUST 可在设置中配置。WYSIWYG 大小阈值与最大行数共同决定默认编辑模式；源码文档大小阈值只触发打开确认。三项设置不得把文档打开或 WYSIWYG 手动切换变成不可用操作。输入校验见 `document-limits-settings`。

#### Scenario: 用户更改阈值
- **WHEN** 用户在设置中修改所见即所得文档大小或源码文档大小
- **THEN** 新阈值适用于下一次文件打开操作
- **THEN** 之前打开的文件不受影响

#### Scenario: 用户更改行数阈值
- **WHEN** 用户在设置中修改最大行数
- **THEN** 新行数阈值适用于下一次文件打开操作
- **THEN** 之前打开的文件不受影响

### Requirement: UI降级
系统 MUST 为因超过 WYSIWYG 大小或最大行数阈值而默认以源码模式打开的文档提供紧凑、非阻塞的提示。提示 MUST 位于当前文档标签栏下方、编辑区内容上方；提供“切换到所见即所得”操作和仅图标 X 关闭操作。提示文案 MUST 说明自动打开模式和用户仍可切换，不得声称 WYSIWYG 切换被阈值禁止或承诺内容一定正常渲染。提示整体悬停时 MUST 提示用户可在“设置 → 高级 → 文档处理”调整所见即所得文档大小和最大行数。

#### Scenario: 降级模式指示器可见
- **WHEN** 活动文档超过 WYSIWYG 大小或最大行数阈值且当前为源码模式，提示未被关闭
- **THEN** 显示低高度、与主题强调色协调的浅黄色提示条
- **THEN** 提示包含“已在源码模式打开”、可切换说明和 WYSIWYG 切换按钮

#### Scenario: 悬停提示阈值设置位置
- **WHEN** 用户悬停提示条任意位置
- **THEN** 显示大小与行数阈值可在设置路径中修改的提示，不要求点击图标或弹出 toast

#### Scenario: 大型等级的降级栏可取消
- **WHEN** 用户点击提示条的 X 按钮
- **THEN** 当前文档的提示隐藏且不再阻止模式切换
- **THEN** X 的悬停提示为“关闭提示”

#### Scenario: 切换后提示消失
- **WHEN** 用户通过提示按钮或工具栏切换到所见即所得
- **THEN** 提示隐藏，WYSIWYG 能否进入仅由正常 Markdown 安全往返检查决定

#### Scenario: 根据只读状态显示降级栏操作
- **WHEN** 文档处于既有只读预览状态
- **THEN** 提示不得提供 WYSIWYG 切换操作
