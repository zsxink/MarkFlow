# MarkFlow 界面设计规范

本文记录 MarkFlow 当前桌面界面的稳定布局与视觉约定，供界面迭代和原型维护时参考。产品行为以应用实现及 `openspec/specs/` 中的功能规范为准；像素尺寸和组件细节以当前代码为准。

## 界面结构

应用主窗口由原生窗口标题栏、顶部工具栏、文件/大纲侧栏、Markdown 编辑区和底部状态栏组成。macOS 窗口控制按钮与当前文档标题由原生标题栏承载。侧栏可折叠并可调整宽度；编辑区随窗口尺寸自适应。

## 视觉原则

- 浅色界面以暖白和白色表面为主，使用低对比度边线分隔区域，并以陶土色作为强调色。
- 深色和护眼主题沿用相同的布局层级与状态表达，并分别适配背景、文字和强调色。
- 工具栏及界面控件使用系统无衬线字体；Markdown 正文使用便于长文阅读的衬线字体；代码使用等宽字体。
- 工具栏图标保持一致的线性风格、视觉尺寸和交互热区。悬停、按下和选中状态应清楚可辨。
- 编辑内容居中排布并限制行宽，正文保留稳定的段落节奏、页边距和标题层级。

## 编辑与导航

- 所见即所得模式直接展示 Markdown 排版效果；源码模式用于查看和编辑原始 Markdown。
- 侧栏在文件树和标题大纲之间切换。文件树用于浏览和管理工作区内容；大纲条目对应文档标题层级。
- 状态栏展示文档统计、光标位置、当前编辑模式及常用视图入口。
- 设置面板按类别组织选项，并应能从工具栏或状态栏入口打开和关闭。

## 原型维护

当应用布局、图标、间距、主题或交互发生变化时，应核对实际组件和 `src/styles/`，并同步更新 `openspec/ui-design/index.html` 与 `openspec/ui-design/SPEC.md`。原型中的示例文档使用仓库 README（中英文）和本设计规范，不应复制无关截图中的 Markdown 内容。原型交互仅用于展示和评审，不代替真实应用行为。
