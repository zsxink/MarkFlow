# Document limits settings

## Purpose

定义文档大小/行数上限作为用户设置的行为契约：设置面板分组与持久化（TS/Rust 两侧同步）、自动模式判定统一读取并对新打开文档立即生效、输入校验与错误回显、源码大小超限确认引用实际生效上限。

## Requirements

### Requirement: 设置面板文档上限分组与持久化

系统 MUST 在设置面板「高级 → 文档处理」中提供所见即所得文档大小、源码文档大小和最大行数三项阈值设置。前两项使用数字输入框与 KB/MB 单位选项，最大行数使用数字输入框；字段显示当前值，默认分别为 1MB、10MB、100 万行。数字输入框尺寸 MUST 足以完整输入 9 位数；KB/MB 单位控件宽度以容纳选项文字为准（原型采用 56px）；数值单位文字“秒”“行”不得绘制为带边框控件。阈值保存后 MUST 持久化到 `settings.json` 并在重启后保持，TS/Rust 设置结构往返不得丢失字段。旧配置中已删除的节点数/文本长度设置 MUST 静默忽略，并在下次保存时剥离，不触发迁移或报错。

#### Scenario: 分组显示当前值并持久化
- **WHEN** 用户打开文档处理设置并编辑合法值
- **THEN** 页面显示 9 位数可完整输入的数字框、紧凑单位选择和对应默认值说明
- **WHEN** 用户保存设置并重启
- **THEN** 值按所选单位换算为字节并从 `settings.json` 正确恢复

#### Scenario: 设置往返不丢失字段
- **WHEN** 设置保存后，后端执行读取、修改并重新保存设置的操作
- **THEN** 所见即所得大小、源码大小和最大行数均保持原值

#### Scenario: 旧配置残留字段被剥离
- **WHEN** 旧配置中含有节点数或文本长度限制字段
- **THEN** 加载不报错并使用现行默认设置
- **THEN** 下次保存后旧字段不再写入

### Requirement: 档位判定与准入分类从三项设置读取阈值

打开策略 MUST 从同一份用户设置读取所见即所得大小、源码大小和最大行数阈值；缺失或非法时回落到 1MB、10MB、100 万行默认值。阈值修改 MUST 对下一次打开的文档生效，已打开文档 MUST NOT 被自动切换。文件大小与最大行数共同决定自动模式：任一超过 WYSIWYG 阈值时默认以源码模式打开；源码大小阈值只触发打开确认，用户确认后仍须允许打开。WYSIWYG 和行数阈值不得阻止用户手动切换到 WYSIWYG，切换按正常 Markdown 安全往返流程执行，不得以节点数、块级结构数量或其他复杂度预算作为额外门禁。

#### Scenario: 档位判定使用自定义配置
- **WHEN** 用户把所见即所得文档大小设为 512KB 后打开一个 800KB 的文档
- **THEN** 该文档默认以源码模式打开并显示可切换提示

#### Scenario: 准入分类使用自定义阈值
- **WHEN** 用户把所见即所得文档大小从 1MB 提高到 2MB 后打开一个 1.5MB 的文档
- **THEN** 该文档默认以所见即所得模式打开，因为大小和行数均未超过设置阈值

#### Scenario: 超限文档手动切换到所见即所得
- **WHEN** 超过 WYSIWYG 大小阈值的文档通过独立安全资格检查，且用户主动切换
- **THEN** 文档进入 WYSIWYG 并渲染内容

#### Scenario: 大小或行数阈值不阻止手动切换
- **WHEN** 文档因超过 WYSIWYG 大小或最大行数阈值而以源码模式打开，且内容可安全往返
- **THEN** 用户手动切换后文档按正常 WYSIWYG 流程加载，不因大小、行数、节点数或块级结构数被拒绝

#### Scenario: 源码大小超限确认后打开
- **WHEN** 文档大小超过源码文档大小阈值且用户在确认弹窗中选择继续
- **THEN** 系统仍打开文档并以源码模式显示
- **WHEN** 用户在确认弹窗中取消
- **THEN** 系统取消本次打开操作

#### Scenario: 设置缺失时回落默认值
- **WHEN** 设置文件缺少一项阈值
- **THEN** 对应默认值为 1MB、10MB 或 100 万行，打开行为保持确定

#### Scenario: 结构复杂度预算拦截碎块文档
- **WHEN** 文档包含大量块级结构，但内容能够通过正常的 Markdown 安全往返检查
- **THEN** 不依据节点数或结构复杂度预算拒绝 WYSIWYG 加载

### Requirement: 文档上限输入校验与错误回显

所有阈值数值 MUST 大于 0；源码文档大小 MUST 大于或等于所见即所得文档大小。非法输入 MUST 在该设置分组内显示错误、拒绝保存非法值，并在恢复合法后允许保存。

#### Scenario: 非法输入回显错误且不写入
- **WHEN** 用户将源码文档大小设为小于所见即所得文档大小的值
- **THEN** 分组内显示错误提示，该非法值不被保存，生效阈值保持最近一次合法值

#### Scenario: 非正数被拒绝
- **WHEN** 用户在任一数值字段输入 0 或负数
- **THEN** 分组内显示错误提示，该值不被保存

#### Scenario: 体积阈值至少为一个字节
- **WHEN** 用户输入一个换算并取整后小于 1 字节的体积阈值
- **THEN** 分组内显示字段错误并拒绝保存

#### Scenario: 恢复合法后可正常保存
- **WHEN** 用户将阈值修正为大于零且大小关系合法的值
- **THEN** 错误提示消失且设置正常保存

### Requirement: 超限提示引用实际生效上限

文档超过所见即所得大小或行数阈值而默认以源码模式打开时，提示 MUST 说明该自动模式原因并告知用户仍可手动切换。提示 MUST NOT 声称阈值禁止切换或承诺渲染安全；具体阈值可通过提示悬停说明指向设置页查看。

#### Scenario: 源码模式提示说明自动模式原因
- **WHEN** 文档因超过所见即所得大小或行数阈值而默认以源码模式打开
- **THEN** 提示说明该自动模式原因并提供手动切换操作
- **THEN** 提示悬停说明用户可前往“设置 → 高级 → 文档处理”查看和修改阈值
