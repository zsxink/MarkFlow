# Proposal

## Why

MarkFlow 的单文档切换会打断跨笔记阅读与编辑，并丢失编辑器历史。Issue #345 的标签栏原型已确认，需要将目标交互落入真实应用，确保每个文档的内容、历史和保存安全互不影响。

## What Changes

- 增加编辑区上方 36px 标签栏，复用已确认的视觉规格，支持脏标记、同名路径区分、横向滚动、关闭与新建。
- 建立窗口内多文档会话；切换无需未保存确认，保留完整撤销历史、模式、滚动、保真会话与磁盘基线。
- 单标签关闭和窗口关闭逐一处理未保存内容，支持恢复最近关闭标签及循环切换快捷键。
- 外部变更投递到所有打开文档；后台冲突保留内存，激活时明确提示，禁止自动保存静默覆盖。
- 首版最多 10 个标签，达到上限提示并拒绝新增，已有标签仍可切换；不自动驱逐或丢弃内容。会话仅在当前进程内保存，不跨重启恢复。
- Finder 多文件打开进入同一窗口多个标签；显式“新窗口打开”入口继续创建独立窗口。

## Capabilities

### New Capabilities

- `document-tabs`: 标签栏、多文档隔离、容量与恢复关闭、外部变更及操作串行化。

### Modified Capabilities

- `active-document-state`: 从单文档转换为集合中的活动文档，路径操作覆盖已打开标签。
- `keyboard-shortcuts`: 新建/关闭/恢复/循环切换标签及模态快捷键保护。
- `sidebar`: 打开文件复用标签，移除切换确认，关闭时确认，外部事件按文档处理。

## Impact

影响 editor 状态和源码编辑器、opaque 会话、图片草稿、文件操作、文件树事件、全局快捷键、工具栏/菜单、窗口生命周期、Rust 外部打开入口，以及对应测试和界面规范。保留单个可见编辑器，避免 N 个隐藏渲染实例；不增加依赖。不包含分屏、拖拽排序、跨窗口共享或重启恢复。
