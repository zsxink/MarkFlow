# Spec Delta

## MODIFIED Requirements

### Requirement: 段首被转义块级前缀往返保真
对以被转义块级前缀开头的合法段落（如 `6\. 正文`、`\- foo`、`\# foo`、`\---`、`\> foo`、`\` `` `` `foo`、`\<div> foo`），系统 MUST 在序列化时对该段落内每一行的行首补回反斜杠转义（段落含软换行时包括全部续行，而非仅首行），使序列化结果再次解析时仍为普通段落而非被当作有序列表、无序列表、标题、分隔线、块引用、围栏代码块或 HTML 块。Setext 下划线整行（`===` H1 与 `-`/`--` H2）MUST 仅在段落非首行时补转义（首行是普通文本，无前导行可下划线）。空格分隔的 thematic break 形态（同一字符 `*`/`-`/`_` 重复 3+ 次、以 1-3 空格分隔）同样 MUST 补转义首字符。上述行首判定 MUST 允许 1-3 个前导空格缩进（CommonMark 块级起始的有效缩进范围）：反斜杠转义 MUST 插入在前导空格之后、前缀字符之前，且前导空格 MUST 在段落文本与语义指纹中逐字节保留；4 个及以上空格或制表符缩进的行是懒延续（不构成块级起始），MUST NOT 补转义。文档经历 Markdown → WYSIWYG → Markdown 往返后 MUST 保留文本内容与段落语义。

#### Scenario: 字面有序列表标记的段落可进入 WYSIWYG
- **WHEN** 文档包含以被转义的「数字句点」开头的独立段落，如 `6\. 这是一段以转义数字开头的正文`、`1\. 另一段`、`10\. 第三段`
- **THEN** 序列化输出保留反斜杠（`6\. 正文`），再次解析仍为同一普通段落
- **THEN** 往返校验通过，文档可进入可编辑 WYSIWYG，编辑保存后语义不变

#### Scenario: 数字后带点或括号的多种空白均保真
- **WHEN** 段首为 `数字.` 或 `数字)` 且后随空格、制表符或行尾，如 `6\.  正文`、`6\.\t正文`、`5\) 正文`、长数字 `999999999\. x`
- **THEN** 序列化将行首 `数字[.)]` 补为 `数字\[.)]`，再次解析仍为普通段落
- **THEN** 往返校验通过

#### Scenario: 被转义的无序列表标记段落保真
- **WHEN** 文档包含以被转义的 `-` 或 `+` 开头且后随空白的段落，如 `\- foo`、`\+ foo`
- **THEN** 序列化补回反斜杠（`\- foo`、`\+ foo`），再次解析仍为普通段落而非列表项
- **THEN** 往返校验通过

#### Scenario: 被转义的 ATX 标题标记段落保真
- **WHEN** 文档包含以被转义的 `#`-`######` 开头且后随空白的段落，如 `\# foo`、`\### foo`
- **THEN** 序列化补回反斜杠，再次解析仍为普通段落而非标题
- **THEN** 往返校验通过

#### Scenario: 被转义的分隔线/Setext 下划线整行保真
- **WHEN** 文档的单个段落以字面分隔线标记组成，如 `\---`、`\***`、`\___`（允许尾随空白）
- **THEN** 序列化补回反斜杠，再次解析仍为普通段落而非分隔线或 Setext 下划线
- **THEN** 往返校验通过

#### Scenario: 软换行续行的块级前缀同样补转义
- **WHEN** WYSIWYG 中一个含软换行的段落，其第二行以字面块级前缀开头（如 `正文第一行\n1. 看起来像列表`、`正文\n# 看起来像标题`、`正文\n- 看起来像条目`、`正文\n---`）
- **THEN** 序列化对每个续行行首补回反斜杠（`1\.`、`\#`、`\-`、`\---`），再次解析仍为同一个多行普通段落
- **THEN** 往返校验通过，续行不被解析为列表、标题或分隔线

#### Scenario: 块引用前缀续行不拆块
- **WHEN** WYSIWYG 中一个含软换行（或两空格硬换行）的段落，其续行以 `>` 开头（如 `正文\n> 看起来像引用`、`正文\n>foo` 无空格形态）
- **THEN** 序列化输出使续行不再构成块引用起始（行首 `>` 经上游文本编码为 `&gt;`，`escapeParagraphMarkdown` 另行保证 `\>` 兜底），再次解析仍为同一个多行普通段落
- **THEN** 往返校验通过，续行不被解析为 blockquote

#### Scenario: 围栏开头续行不拆块
- **WHEN** WYSIWYG 中一个含软换行的段落，其续行以三个及以上反引号或波浪线开头（如 `正文\n``` 看起来像代码`、`正文\n~~~`）
- **THEN** 序列化输出使续行不再构成围栏开始（行首反引号/波浪线经上游逐字符转义，`escapeParagraphMarkdown` 另行保证 `\` 转义兜底），再次解析仍为同一个多行普通段落
- **THEN** 往返校验通过，续行不拆为 fenced code block、后续行不被围栏吞掉

#### Scenario: Setext 下划线续行补转义
- **WHEN** WYSIWYG 中一个含软换行的段落，其非首行是整行 `===`（如 `正文\n===`）
- **THEN** 序列化对续行行首补转义（`\===`），再次解析仍为同一个多行普通段落，上一行不升级为 H1 标题
- **WHEN** 段落首行是 `===`（普通文本，无前导行）
- **THEN** 序列化不对其补转义，首行拼写保持 `===`，再次解析仍为普通段落

#### Scenario: Setext H2 下划线（1-2 连字符整行）续行补转义
- **WHEN** WYSIWYG 中一个含软换行（或两空格硬换行）的段落，其非首行是整行 `-` 或 `--`（允许尾随空白，如 `正文\n--`、`正文\n-`）
- **THEN** 序列化对续行行首补转义（`\--`、`\-`），再次解析仍为同一个多行普通段落，上一行不升级为 H2 标题
- **WHEN** 段落首行是 `-` 或 `--`（普通文本，无前导行）
- **THEN** 序列化不对其补转义，首行拼写保持 `-`/`--`，再次解析仍为普通段落

#### Scenario: 空格分隔 thematic break 续行补转义
- **WHEN** WYSIWYG 中一个含软换行的段落，其续行是空格分隔的 thematic break 形态——同一字符 `*`/`-`/`_` 重复 3+ 次、以 1-3 空格分隔（如 `正文\n* * *`、`正文\n_ _ _`、`正文\n- - -`、`正文\n*  *  *` 多空格形态，允许尾随空白）
- **THEN** 序列化对续行行首补转义（`\* * *`、`\_ _ _`；`-` 形态由 bullet 规则先行命中转义为 `\- - -`），再次解析仍为同一个多行普通段落，不拆出分隔线
- **THEN** 往返校验通过；混合字符（`* - *`、`_ - _`）与两个字符（`* *`、`_ _`）形态不构成 thematic break，不命中空格分隔 thematic break 转义规则（`*` 开头形态仍是 CommonMark 列表标记，由 bullet 规则补转义；`_` 开头形态保持字面不变）

#### Scenario: HTML 块起始形态续行不拆块
- **WHEN** WYSIWYG 中一个含软换行的段落，其续行以 `<div>`、`<!--`、`<script>` 等 HTML 块起始形态开头（如 `正文\n<div>看起来像 HTML`）
- **THEN** 序列化输出使续行不再构成 HTML 块开始（行首 `<` 经上游文本编码为 `&lt;`，`escapeParagraphMarkdown` 另行保证 `\<` 兜底），再次解析仍为同一个多行普通段落
- **THEN** 往返校验通过，续行走普通段落路径而非 opaque html-block 识别

#### Scenario: 以被转义块引用/围栏/HTML 开头的段落首行保真
- **WHEN** 文档包含以被转义形态开头的独立段落，如 `\> foo`、`\`\`\` foo`、`\<div> foo`
- **THEN** 序列化输出再次解析仍为普通段落而非 blockquote、围栏代码块或 HTML 块（行首不再构成原生块起始；拼写由上游文本编码决定，如 `&gt; foo`）
- **THEN** 往返校验通过

#### Scenario: 缩进块级前缀续行补转义且缩进空格保真
- **WHEN** WYSIWYG 中一个含软换行（或两空格硬换行）的段落，其续行以 1-3 个前导空格 + 块级前缀开头（如 `正文\n  ---`、`正文\n   ===`、`正文\n  - foo`、`正文\n  1. x`、`正文\n  # x`、`正文\n > 引用`、`正文\n  <div>`、`正文\n  * * *`）
- **THEN** 序列化把反斜杠转义插入在前导空格之后、前缀字符之前（`  \---`、`   \===`、`  \- foo`、`  1\. x`、`  \# x`、` \> 引用`、`  \<div>`、`  \* * *`），再次解析仍为同一个多行普通段落——不升级 Setext 标题、不拆出列表/标题/引用/HTML 块/分隔线
- **THEN** 续行文本的前导空格逐字节保留，语义指纹一致；含此类段落的文档准入放行，编辑保存不冲突，authored 磁盘形（如 `正文\n  \- foo`）往返字节稳定

#### Scenario: 缩进 Setext 下划线续行补转义、首行不转义
- **WHEN** WYSIWYG 中一个含软换行的段落，其非首行是 1-3 个前导空格 + 整行 `=`/`-`/`--`/`---`（如 `正文\n   ===`、`正文\n  --`、`正文\n  ---`）
- **THEN** 序列化对续行在缩进后补转义（`   \===`、`  \--`、`  \---`），再次解析仍为同一个多行普通段落，上一行不升级为标题
- **WHEN** 段落首行是 1-3 个前导空格 + 整行 `--`/`===`（无前导行可下划线）
- **THEN** 序列化不对其补转义，首行拼写保持原样

#### Scenario: 4+ 空格或制表符缩进的懒延续不补转义
- **WHEN** 段落续行有 4 个及以上前导空格或以制表符开头（如 WYSIWYG 内 `正文\n    - foo`、`正文\n\t- foo`，或 authored 磁盘形 `正文\n    - foo`）
- **THEN** 序列化不补转义（此类缩进是懒延续，重解析不拆块、空白逐字保留）；authored 形往返字节稳定

#### Scenario: 已转义缩进前缀不双重转义
- **WHEN** 段落某行为 1-3 个前导空格 + 已带反斜杠转义的前缀（如函数输入 `  \- foo`、`  \---`、authored 磁盘形 `正文\n  \- foo` 加载后再次保存）
- **THEN** 序列化不再追加转义，拼写保持单反斜杠形态
