# wysiwyg-markdown-round-trip Specification (delta)

## ADDED Requirements

### Requirement: 转义行首块级前缀的段落往返保真

受支持语法边界 MUST 包含以被转义块级前缀开头的普通段落。对 `6\. 正文`、`\- foo`、`\+ foo`、`\# foo`、`\---` 这类「无标题符号、单独成行、以字面块级前缀开头」的段落，序列化 MUST 补回行首反斜杠转义，使序列化结果重新解析后仍为语义相同的普通段落，而非被当作有序列表、无序列表、标题或分隔线。往返校验（`verifyAdmission`）MUST 对这类文档通过，允许进入可编辑 WYSIWYG。

#### Scenario: 字面有序列表标记的段落可进入 WYSIWYG

- **WHEN** 文档包含以被转义数字句点开头的独立段落，如 `6\. 这是一段以转义数字开头的正文`
- **THEN** 序列化输出保留反斜杠（`6\. 正文`），再次解析仍为同一普通段落
- **THEN** 往返校验通过，文档进入可编辑 WYSIWYG，编辑保存后语义不变

#### Scenario: 列表/标题/分隔线前缀段落往返保真

- **WHEN** 文档包含以被转义的 `- ` / `+ ` / `# ` / `---` 开头的独立段落
- **THEN** 序列化补回反斜杠，再次解析仍为普通段落
- **THEN** 往返校验通过

#### Scenario: 真实块级结构不受影响

- **WHEN** 文档包含真实的有序列表、无序列表、任务列表、引用、标题、分隔线、嵌套列表或强调等受支持结构
- **THEN** 这些结构仍按各自节点渲染器输出相同的 Markdown，段落转义逻辑不改写它们
- **THEN** 往返校验通过
