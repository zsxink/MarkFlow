# Spec Delta

## Purpose

定义文档大小/行数上限作为用户设置的行为契约：设置面板分组与持久化（TS/Rust 两侧同步）、各链路统一读取与对新打开文档立即生效、输入校验与错误回显、超限提示引用实际生效数值。

## ADDED Requirements

### Requirement: 设置面板文档上限分组与持久化

系统 MUST 在设置面板提供「文档大小/行数上限」分组，包含以下可配置项，字段值 MUST 来自当前设置，保存后 MUST 持久化到 `settings.json` 并在重启后保持：

- 所见即所得准入体积上限与行数上限；
- 所见即所得（ProseMirror）节点数上限与文本长度上限；
- 大文件与超大文件档位的体积阈值与行数阈值。

持久化层 MUST 保证新增设置字段在 TS 与 Rust 两侧结构体中同步声明，使后端任何「读取-修改-保存」往返不丢弃这些字段。

#### Scenario: 分组显示当前值并持久化

- **WHEN** 用户打开设置面板的文档上限分组
- **THEN** 各字段显示当前设置值（体积字段以 KB 为单位展示）
- **WHEN** 用户修改为合法值并保存
- **THEN** 值持久化到 `settings.json`，重启应用后保持

#### Scenario: 设置往返不丢失字段

- **WHEN** 用户保存文档上限设置后，后端执行任何会读取并回写设置的操作（如记录最近文件）
- **THEN** 文档上限各字段的值不被丢弃或重置为默认

### Requirement: 各链路统一从设置读取阈值并对新打开文档立即生效

档位判定、所见即所得准入分类与编辑器复杂度限制 MUST 从同一份用户设置读取阈值；设置缺失或非法时 MUST 回落默认值（256KB/10,000 行准入、10,000 节点/500,000 字符、1MB/10MB/5,000/50,000 行档位）。阈值修改 MUST 对新打开的文档立即生效，无需重启；已打开的文档 MUST NOT 受影响。阈值计算函数 MUST 保持纯函数性质，通过参数注入配置，不直接依赖状态存储。

#### Scenario: 档位判定使用自定义配置

- **WHEN** 用户把大文件体积阈值设为 512KB 后打开一个 800KB 的文档
- **THEN** 该文档按大文件（Large）档位处理

#### Scenario: 准入分类使用自定义阈值

- **WHEN** 用户把所见即所得准入体积上限从 256KB 提高到 1MB 后打开一个 300KB 的文档
- **THEN** 该文档被判定可进入所见即所得，不再因体积被拒

#### Scenario: 复杂度限制使用自定义上限

- **WHEN** 用户把节点数上限从 10,000 下调后打开一个超过新上限的文档并进入所见即所得
- **THEN** 编辑器按新上限触发复杂度限制提示

#### Scenario: 设置缺失时回落默认值

- **WHEN** 设置中未包含某阈值字段（如旧配置文件升级后）
- **THEN** 对应链路使用与现状一致的默认阈值，行为不突变

### Requirement: 输入校验与错误回显

文档上限输入的校验规则：

- 恒定规则：所有数值必须大于 0。
- 排序规则（仅对用户本次实际修改的字段所涉约束生效）：大文件体积阈值严格小于超大文件体积阈值；大文件行数阈值严格小于超大文件行数阈值；所见即所得准入体积上限不超过大文件体积阈值；准入行数上限不超过大文件行数阈值。

历史默认组合本身不满足「准入行数 ≤ 大文件行数」（10,000 > 5,000），因此未触及相关字段对的存量配置 MUST 允许原样保存，不得因历史默认值阻塞任意设置的保存。

非法输入 MUST 在分组内回显明确错误并拒绝保存该值；恢复合法后错误消失且可正常保存。

#### Scenario: 非法输入回显错误且不写入

- **WHEN** 用户把大文件体积阈值改为大于等于超大文件体积阈值的值
- **THEN** 分组内显示错误提示，该非法值不被保存，生效阈值保持最近一次合法值

#### Scenario: 非正数被拒绝

- **WHEN** 用户在任一数值字段输入 0 或负数
- **THEN** 分组内显示错误提示，该值不被保存

#### Scenario: 恢复合法后可正常保存

- **WHEN** 用户修正非法输入为合法值
- **THEN** 错误提示消失，新值正常保存并生效

#### Scenario: 存量默认组合不阻塞保存

- **WHEN** 设置保持默认值（准入行数上限 10,000 大于大文件行数阈值 5,000）且用户仅修改与该约束无关的字段（如节点数上限）
- **THEN** 保存成功，不因历史默认组合触发错误

### Requirement: 超限提示引用实际生效数值

因超过阈值而向用户展示的提示文案 MUST 引用实际生效的配置数值，不得引用与配置脱节的硬编码常量。

#### Scenario: 准入拒绝提示包含配置上限

- **WHEN** 文档因体积超过准入上限被保留在源码模式，且用户已把准入上限设为 512KB
- **THEN** 提示文案包含文档实际体积与 512KB 这一实际生效上限

#### Scenario: 复杂度限制提示包含实际上限

- **WHEN** 文档节点数超过配置的节点数上限触发复杂度限制提示
- **THEN** 提示文案包含实际上限数值
