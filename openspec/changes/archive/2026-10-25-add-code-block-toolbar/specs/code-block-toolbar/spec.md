# Spec Delta

## Purpose

WYSIWYG 模式下普通围栏代码块的右上角悬浮工具条交互：一键复制源码纯文本、查看并切换语言，且不干扰正文编辑与图表块现有行为。

## ADDED Requirements

### Requirement: 复制源码一键反馈

WYSIWYG 普通代码块工具条 MUST 提供复制按钮，点击后将块内源码纯文本（不含语法高亮标记、不含 fence 标记）写入系统剪贴板，并给出纯 DOM 成功反馈（图标短暂变 ✓ 后还原）。

#### Scenario: 点击复制
- **WHEN** 用户点击代码块工具条的复制按钮
- **THEN** 剪贴板内容等于该块源码纯文本，按钮图标短暂变为 ✓ 并在约 1.2 秒后还原

#### Scenario: 复制不改动文档
- **WHEN** 复制按钮被点击（含剪贴板写入失败时）
- **THEN** 文档内容、光标位置不变，不产生撤销历史记录，文档不被标记为脏

### Requirement: 语言显示与下拉切换

工具条 MUST 显示代码块当前语言（无语言时显示「纯文本」占位），点击打开下拉：支持搜索过滤、列出常用语言候选、当前语言带选中标记；输入未列出的语言时原样接受。切换后块内立即按新语言重新高亮，源码模式 fence 标记同步更新且代码内容逐字节不变。

#### Scenario: 无语言块显示占位
- **WHEN** 代码块 language attr 为空
- **THEN** 语言标签显示「纯文本」

#### Scenario: 切换语言重新高亮
- **WHEN** 用户在下拉中选择另一语言
- **THEN** language attr 更新，块内立即按新语言高亮；切到源码模式 fence 标记为新语言，代码内容不变

#### Scenario: 自定义语言兜底
- **WHEN** 用户在下拉输入候选之外的语言并确认
- **THEN** 该语言字符串原样保存为 fence 标记，块内高亮退化为纯文本，不报错

### Requirement: 工具条不干扰编辑与图表块

工具条 MUST 仅在悬停所属代码块（或下拉打开）时可见，不得拦截块内文本选择与光标编辑；mermaid/plantuml 图表块的现有渲染与编辑行为 MUST 不受影响。

#### Scenario: 悬停浮现
- **WHEN** 指针不在代码块上且下拉未打开
- **THEN** 工具条不可见且不拦截指针事件

#### Scenario: 图表块不受影响
- **WHEN** 文档包含 mermaid 或 plantuml 代码块
- **THEN** 图表块不出现普通块工具条，其预览、编辑、设置联动行为与变更前一致

### Requirement: 样式与主题隔离

工具条与下拉样式 MUST 使用编辑器三主题（浅色/深色/护眼）设计 token，且 MUST NOT 进入导出主题或影响导出产物。

#### Scenario: 三主题下可用
- **WHEN** 编辑器在浅色、深色或护眼主题下显示带工具条的代码块
- **THEN** 工具条文字、图标、下拉面板在该主题下对比度可读，无未适配的硬编码颜色

#### Scenario: 导出不受影响
- **WHEN** 执行 HTML/PDF/DOCX 导出
- **THEN** 导出产物不包含工具条与下拉的 DOM 或样式
