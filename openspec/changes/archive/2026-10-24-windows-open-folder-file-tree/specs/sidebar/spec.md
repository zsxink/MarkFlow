# Spec Delta

## ADDED Requirements

### Requirement: 打开工作区后展示文件树

任一侧边栏「打开文件夹」入口（工具栏、侧边栏底部按钮、原生菜单「文件 → 打开文件夹…」及最近文件夹）在用户选定目录后 MUST 将侧边栏切换到「文件」标签页并展开侧边栏，使该工作区的文件树立即可见。三个入口 MUST 行为一致。

#### Scenario: 从原生菜单打开文件夹

- **WHEN** 用户通过菜单栏「文件 → 打开文件夹…」选择一个包含 Markdown 文件的目录
- **THEN** 侧边栏标签页切换到「文件」
- **THEN** 侧边栏处于展开状态
- **THEN** 文件树展示该目录的直接子项
- **THEN** 显示「文件夹已打开」提示

#### Scenario: 从侧边栏底部按钮打开文件夹

- **WHEN** 用户点击侧边栏底部「打开文件夹」并选择一个目录
- **THEN** 侧边栏标签页切换到「文件」并展开
- **THEN** 文件树展示该目录的直接子项

#### Scenario: 侧边栏此前折叠

- **WHEN** 侧边栏处于折叠状态且用户打开一个工作区文件夹
- **THEN** 侧边栏展开并显示「文件」标签页的文件树

#### Scenario: 用户取消选择目录

- **WHEN** 用户在系统目录对话框中选择取消
- **THEN** 侧边栏标签页与展开状态保持原样
- **THEN** 不显示「文件夹已打开」提示

#### Scenario: 打开最近文件夹

- **WHEN** 用户从原生菜单选择一个最近文件夹
- **THEN** 侧边栏切换到「文件」标签页并展示该文件夹的文件树
