# Spec Delta

## ADDED Requirements

### Requirement: WYSIWYG 表格单元格上下留白对称

在 WYSIWYG 模式下，表格单元格 SHALL 使用较紧凑且上下对称的内部留白。此要求同时适用于表头、普通单元格及含多行内容的单元格；文本 MUST 与单元格边框保持可见间隔。单元格留白调整 MUST NOT 改变表格与前后段落之间的外部间距。

#### Scenario: 表头与普通单元格留白对称
- **WHEN** 用户在 WYSIWYG 模式查看含表头和普通数据行的表格
- **THEN** 表头与普通单元格的内容上下留白相等，且行高较原有宽松留白收紧

#### Scenario: 多行单元格内容保留对称间距
- **WHEN** 单元格内容跨越多行显示
- **THEN** 内容块上方与下方留白相等，文本不贴合单元格边框

#### Scenario: 表格周边段落间距不变
- **WHEN** 表格前后存在普通段落
- **THEN** 调整单元格内部留白不改变表格与相邻段落之间的外部间距
