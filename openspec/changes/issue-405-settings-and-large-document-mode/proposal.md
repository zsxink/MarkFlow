# Proposal

## Why

设置页、文档大小策略和编辑区提示之间目前存在不一致：设置阈值被当成 WYSIWYG 的强制准入限制，用户无法手动尝试渲染；项目整体原型也未反映近期确认的设置导航和工作区变化。需要先统一可见交互与后端行为契约，避免原型和实现继续分叉。

## What Changes

- 更新项目整体 HTML 原型与界面规范，并保留主界面现有布局：工具栏横跨顶部，侧栏从工具栏下方开始；补齐通用/外观/编辑器/图片/快捷键/关于设置、系统对应快捷键、PlantUML 公共地址复制反馈、紧凑阈值输入控件及应用图标。
- 当前活动文档名显示在窗口标题栏，未保存时追加 `*`。
- 超过 WYSIWYG 大小或最大行数阈值的文档默认以源码模式打开，在文档标签栏下方显示紧凑浅黄色提示，可切换到 WYSIWYG 或用 X 关闭；提示悬停说明阈值设置位置。
- 仅以文档大小和行数决定是否默认进入 WYSIWYG；超限文档默认源码打开，但仍可按正常流程手动切换到 WYSIWYG，不以节点数或结构复杂度门禁拦截。超过源码最大大小时先确认，用户确认后仍打开。
- 更新文档分级、设置阈值、WYSIWYG 资格与标签窗口标题相关规范。

## Capabilities

### New Capabilities

- `settings-panel`: 规范设置弹窗的分类导航、选中状态和关于页信息布局。

### Modified Capabilities

- `document-size-tier`: 调整大文档默认模式与提示栏交互，并明确大小阈值不是手动切换锁。
- `document-limits-settings`: 说明 WYSIWYG 大小设置用于自动打开模式选择，设置页显示和阈值持久化契约保持一致。
- `wysiwyg-markdown-reconciliation`: 移除大小、行数、节点数和结构复杂度作为 WYSIWYG 拒绝原因，保留 Markdown 安全往返检查。
- `document-tabs`: 规范活动文档窗口标题及未保存星号。
- `keyboard-shortcuts`: 明确快捷键设置页和界面提示按当前系统显示修饰键。

## Impact

- 原型与规范：`openspec/ui-design/原型.html`、`openspec/ui-design/SPEC.md`。
- 行为实现候选：文档元数据/分级与打开流程、WYSIWYG 资格检查与模式切换、文档提示条、设置持久化与设置面板、活动标签投影及窗口标题。
- 后端关注：设置 JSON 中 WYSIWYG/源码大小和最大行数的 TS/Rust 往返一致；文件大小/行数元数据在打开前可用；源码大小不得小于 WYSIWYG 大小；源码大小超限通过可确认并可继续的打开流程处理。
