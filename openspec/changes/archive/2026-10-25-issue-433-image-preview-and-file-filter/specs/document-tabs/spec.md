# Spec Delta

## ADDED Requirements

### Requirement: 图片预览标签会话

标签页系统 SHALL 支持图片预览类型的标签会话，与文档标签共享同一标签栏与交互（激活、关闭、重开、滚入视野、`role=tab` 属性）。图片标签 SHALL 遵循与文档标签相同的容量上限（20）与按 path 去重语义（重复打开激活既有标签）。图片标签 MUST NOT 具有 dirty 语义：关闭时 MUST NOT 触发保存确认，标签不显示未保存标记。文档标签与图片标签互相切换时，SHALL 正确挂起/恢复编辑器文档上下文（既有 detach/attach 语义），图片标签激活时编辑器内容区 SHALL 让位于预览容器。工作区路径重写（`rewriteDocumentTabPaths`）SHALL 同样作用于图片标签。图片标签 MUST NOT 参与文档外部变更确认流程（无未保存状态）；外部修改/删除图片文件不弹确认对话框。

#### Scenario: 图片标签计入容量与去重

- **WHEN** 已打开 20 个标签（含图片标签）时再打开任意文件
- **THEN** 提示已达上限，与文档标签一致
- **WHEN** 重复打开同一路径的图片文件
- **THEN** 激活既有图片标签，不新建标签

#### Scenario: 图片标签关闭与重开无保存确认

- **WHEN** 用户关闭（或经「重新打开关闭的标签」恢复）一个图片预览标签
- **THEN** 直接关闭/恢复，不出现保存确认对话框，恢复后重新渲染预览

#### Scenario: 文档与图片标签互切保留编辑状态

- **WHEN** 用户在编辑中的文档标签与图片预览标签之间来回切换
- **THEN** 文档的光标/滚动/撤销栈等会话状态完整保留（既有挂起恢复语义），图片标签每次激活显示预览容器、编辑器内容区隐藏

#### Scenario: 工作区重命名同步图片标签路径

- **WHEN** 工作区根路径被重写（如文件夹更名）且存在指向其内图片的预览标签
- **THEN** 图片标签路径同步重写，预览仍指向新路径下的同一文件

#### Scenario: 外部删除图片文件不弹确认

- **WHEN** 图片预览标签处于后台时其文件被外部删除
- **THEN** 不触发外部变更确认流程；标签保留，激活时按预览加载失败降级处理
