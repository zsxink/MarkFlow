# Spec Delta

## MODIFIED Requirements

### Requirement: 关闭工作区入口

系统 SHALL 在以下位置提供「关闭文件夹」入口，且所有入口 MUST 执行同一关闭流程：

- 文件树空白区域的右键菜单（存在工作区时显示，与无工作区时「打开文件夹」入口的位置对应）；
- 文件树**文件节点**的右键菜单（存在工作区时显示）；
- 文件树**文件夹节点**的右键菜单（存在工作区时显示）；
- 原生菜单「文件 → 关闭文件夹」（存在工作区时可用，无工作区时禁用）。

无工作区时文件树右键菜单 MUST NOT 显示「关闭文件夹」入口。内部实现命名（command id `close-workspace`、`closeWorkspaceFolder`、`workspacePath`）MUST 保持不变，仅用户可见文案统一为「文件夹」。

#### Scenario: 有工作区时右键文件树空白区域

- **WHEN** 已打开工作区，用户右键点击文件树空白区域
- **THEN** 右键菜单包含「关闭文件夹」与「复制文件夹路径」项，点击「关闭文件夹」后执行统一关闭流程

#### Scenario: 有工作区时右键文件或文件夹节点

- **WHEN** 已打开工作区，用户右键点击文件节点或文件夹节点
- **THEN** 右键菜单在既有节点操作之外包含「关闭文件夹」项，点击后执行与空白区域入口相同的关闭流程

#### Scenario: 无工作区时右键文件树空白区域

- **WHEN** 未打开任何工作区，用户右键点击文件树任意位置（空白区域、文件节点或文件夹节点）
- **THEN** 右键菜单不包含「关闭文件夹」项

#### Scenario: 原生菜单按工作区状态启用

- **WHEN** 原生菜单「文件」菜单展开
- **THEN** 已打开工作区时「关闭文件夹」可用；无工作区时该项禁用

#### Scenario: 各入口执行同一关闭流程

- **WHEN** 用户从右键菜单（空白区域/文件节点/文件夹节点）或原生菜单任一入口触发「关闭文件夹」
- **THEN** 所有入口产生相同的关闭结果（状态重置、文件树空态「请先打开文件夹」、后端清理）

#### Scenario: 用户可见文案不出现「工作区」

- **WHEN** 用户查看文件树右键菜单、原生菜单或关闭/未打开时的 toast 提示
- **THEN** 文案统一使用「文件夹」，不出现「工作区」字样
