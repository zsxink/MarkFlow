# wysiwyg-markdown-round-trip Specification (delta)

## ADDED Requirements

### Requirement: 交互编辑后的表格往返保真

当 WYSIWYG 内通过表格交互（悬停工具条 / 单元格右键菜单）对 GFM 表格执行行列增删、表头切换或对齐设置后，文档切换回源码模式或保存时，序列化输出 MUST 仍是合法 GFM 表格，且重新解析后单元格数据、行内格式与列对齐语义保持不变。交互产生的对齐属性 MUST 通过对齐标记行（`:---` / `:---:` / `---:`）持久化，不得在往返中丢失。

#### Scenario: 对齐设置往返保留
- **WHEN** 用户在 WYSIWYG 中将某列设为居中对齐并执行源码往返
- **THEN** 序列化输出该列对齐标记为 `:---:`
- **THEN** 重新解析后该列单元格的语义对齐仍为居中

#### Scenario: 交互增删行列后往返保真
- **WHEN** 用户通过表格交互删除一行或一列，再执行往返
- **THEN** 输出为列数一致的合法 GFM 表格
- **THEN** 保留单元格文本与行内格式，未参与操作的行列内容不变

#### Scenario: 表头切换往返保真
- **WHEN** 用户切换表头行状态后执行往返
- **THEN** 首行保持其作为表头行解析回读的状态，数据行与分隔行结构合法
