# Spec Delta

## Purpose

定义 Windows/Linux 无边框窗口的自绘标题栏行为：窗口控制按钮、拖拽移动与双击最大化，并明确 macOS 保持系统默认标题栏不变的边界，使应用顶部只保留一行横栏。

## ADDED Requirements

### Requirement: 平台窗口外观

Windows/Linux 上应用主窗口与辅助窗口 MUST 以无边框模式运行（不渲染系统标题栏），窗口控制由应用工具栏行承担，使窗口顶部只有工具栏一行；macOS MUST 保持系统默认标题栏与现有窗口行为完全不变。

#### Scenario: Windows/Linux 顶部单行

- **WHEN** 用户在 Windows 或 Linux 启动应用（主窗口或通过「打开文件」创建的辅助窗口）
- **THEN** 窗口不显示系统标题栏
- **THEN** 窗口控制按钮与工具栏按钮处于同一水平行，不再有独立的系统标题栏行

#### Scenario: macOS 保持现状

- **WHEN** 用户在 macOS 启动应用
- **THEN** 窗口使用系统默认标题栏，工具栏仍为独立一行
- **THEN** 工具栏中不出现自绘窗口控制按钮，工具栏空白处不接管窗口拖拽

### Requirement: 窗口控制按钮

无边框窗口 MUST 在工具栏右侧提供最小化、最大化/还原、关闭三个窗口控制按钮；非无边框窗口（macOS、浏览器环境）MUST NOT 显示该按钮组。关闭按钮 MUST 走与系统关闭一致的确认链路，不得绕过未保存文档检查。

#### Scenario: 无边框窗口显示控制按钮

- **WHEN** 无边框窗口完成初始化
- **THEN** 工具栏右侧显示最小化、最大化/还原、关闭按钮
- **THEN** 点击最小化按钮后窗口最小化
- **THEN** 点击最大化按钮后窗口最大化，再次点击（或点击还原图标）后还原

#### Scenario: 关闭按钮不绕过脏检查

- **WHEN** 用户在存在未保存修改的文档时点击关闭按钮
- **THEN** 应用先呈现与点击系统关闭一致的未保存确认流程，确认后才关闭窗口

#### Scenario: 非无边框窗口不显示

- **WHEN** 窗口带系统标题栏（macOS）或页面运行在非 Tauri 环境
- **THEN** 工具栏中不渲染窗口控制按钮组，工具栏外观与行为与现状一致

### Requirement: 窗口拖拽与双击最大化

无边框窗口 MUST 允许在工具栏的空白区域（容器背景、弹性占位、分隔线）按下拖动来移动窗口，双击空白区域 MUST 在最大化与还原之间切换；工具栏中的功能按钮、菜单入口 MUST NOT 触发拖拽，其点击行为不受影响。

#### Scenario: 空白区拖动窗口

- **WHEN** 用户在工具栏空白区域（非按钮、非菜单入口）按住左键拖动
- **THEN** 窗口跟随拖动移动

#### Scenario: 双击最大化与还原

- **WHEN** 用户在工具栏空白区域双击
- **THEN** 窗口在最大化与还原状态间切换

#### Scenario: 按钮与菜单入口不受拖拽影响

- **WHEN** 用户点击工具栏中的功能按钮、MarkFlow 菜单入口或其下拉菜单
- **THEN** 对应操作正常触发，窗口不发生拖拽移动

### Requirement: 最大化状态图标同步

无边框窗口的窗口控制按钮 MUST 反映当前最大化状态：最大化时显示还原图标，还原时显示最大化图标。

#### Scenario: 图标随窗口状态切换

- **WHEN** 窗口在最大化与还原之间切换（通过按钮、双击或系统快捷键）
- **THEN** 最大化/还原按钮显示与当前状态对应的图标

### Requirement: 初始化失败降级

窗口状态查询或按钮初始化失败时，应用 MUST 保持工具栏原有功能可用，窗口控制按钮组保持隐藏，且失败被记录到结构化日志，不得阻断编辑器启动。

#### Scenario: 查询失败时保持可用

- **WHEN** 窗口装饰状态查询失败（如非 Tauri 环境）
- **THEN** 工具栏按钮与菜单照常工作，窗口控制按钮组保持隐藏
- **THEN** 失败信息写入结构化日志
